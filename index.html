TabGlint — Privacy Policy

Last updated: October 25, 2026.

What TabGlint does

TabGlint indicates confirmed ChatGPT response-stream activity in the titles of Chrome tabs at https://chatgpt.com. It can optionally play one of five original built-in sounds or a user-provided local file when a previously confirmed stream closes normally. It does not determine the semantic completion of the response.

Data accessed and processed

Before you agree to the first-use privacy disclosure, TabGlint does not enumerate ChatGPT tabs or read their titles or identifiers in its popup. The popup shows the privacy disclosure, and you may choose Not now without enabling monitoring. After you explicitly agree, opening the popup reads the identifiers and titles of open ChatGPT tabs to display them, even while monitoring itself is switched off. When monitoring is enabled, it additionally processes selected HTTP request/response metadata (request ID, method, status, the presence of the text/event-stream response type, and timing), plus limited page-structure and tab-availability signals for diagnostics. During background-worker startup, Chrome may deliver up to 128 network event objects before the extension finishes reading the saved consent and monitoring preferences. TabGlint holds only temporary references to these event objects, without inspecting their fields during that interval. If consent and monitoring are not both enabled, the references are discarded without processing their fields, logging them or storing them persistently. The extension reads page titles to apply its indicator; the popup also temporarily displays the titles of open ChatGPT tabs so you can identify them. These titles are not written to the diagnostic log or sent to the publisher. The page-structure observer checks whether assistant DOM nodes change but does not retain their text. These data are used only for tab indicators, related local operation and troubleshooting, not advertising or profiling.

Data not collected

TabGlint does not store the text of ChatGPT prompts or assistant responses. It does not intercept HTTP request or response bodies, SSE frames, cookies, authentication tokens or full URLs with query strings, and it does not record HTTP headers. The only response-header information used for classification is whether the Content-Type denotes an SSE stream. ChatGPT tab titles can contain conversation titles and are displayed temporarily in the popup, but are not retained in diagnostics or transmitted to the publisher. The extension does not monitor browsing activity on other websites.

Storage and retention

Color and sound preferences and a bounded diagnostic event log reside in Chrome's extension-local storage. The diagnostic log contains a maximum of 300 entries and 65,536 bytes, and records are retained for no more than 72 hours subject to Chrome's ability to run cleanup tasks. Old entries may remain past the nominal deadline while the browser is closed or background tasks are delayed; cleanup occurs when the extension can next run. The user can manually copy the diagnostic log; nothing is exported automatically.

For recovery after a Manifest V3 worker restart, active request IDs and associated non-content metadata are stored in chrome.storage.session for the current browser session. If a user selects a custom audio file (maximum 5 MiB inclusive), that file is stored only in the extension's local IndexedDB. This local audio file is not sent to the publisher.

Data transfers and sharing

TabGlint has no extension-operated remote telemetry or analytics endpoint and does not send the data described above to the publisher, advertisers or other third parties. Ordinary requests to ChatGPT are made by the ChatGPT website, not by TabGlint. The extension does not sell user data or use it for personalized advertising.

Control and deletion

On first use of TabGlint 0.6.25, you must explicitly choose I agree — continue before the extension reads ChatGPT tab titles or identifiers or permits monitoring. Choosing Not now leaves consent unset and monitoring disabled. Agreeing opens the normal popup but does not automatically start monitoring: you must separately press Start monitoring. When upgrading from an earlier version without this consent, prior automatic monitoring is disabled and the previous monitoring session state is cleared until you agree and choose Start. Once monitoring has been started, its enabled preference is saved locally so it can resume across extension-worker and browser restarts until you switch it off. The user can stop monitoring from the popup, control colors, choose one of five built-in sounds (No. 3, Gentle Close, is the default), switch sound off, or use a local custom file. The locally stored data and optional custom sound can be removed by deleting the extension's local data or uninstalling the extension; doing so also removes its local settings. The bounded log expires by the retention procedure described above.

Chrome Web Store Limited Use

Use of information obtained through Chrome extension APIs is limited to TabGlint's disclosed single purpose and directly related reliability functions. Information received through Chrome extension APIs is handled under the Chrome Web Store User Data Policy and its Limited Use requirements. This information is used only to provide and maintain TabGlint's disclosed features. It is not sold, used for personalized advertising, shared with advertisers, or transferred for unrelated purposes. The extension does not provide the publisher with remote access to stored data; the publisher does not routinely inspect user data. If a user chooses to copy and share a diagnostic log for support, that sharing is initiated by the user outside the extension's automatic operation.
